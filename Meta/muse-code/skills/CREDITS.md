# Credits / 致谢

Outside work that Muse Core's built-in skills are built on.

Muse Core 内置技能所借鉴的外部成果。

## `skills/grill`

Its name and interview approach — one recommended answer per question,
repository facts researched instead of asked, decisions written down as
they settle — come from the `grilling` skill (and the former
`grill-with-docs` skill) by Matt Pocock (@mattpocockuk),
<https://github.com/mattpocock/skills>. The skill text shipped here is our own.

其名称与访谈式做法——每个问题给出一个推荐答案、事先调研仓库事实而非直接询问、决策在敲定时即记录成文——来自 Matt Pocock（@mattpocockuk）的 `grilling` 技能（以及先前的 `grill-with-docs` 技能），见 <https://github.com/mattpocock/skills>。随附于此的技能正文为我们自己所写。
