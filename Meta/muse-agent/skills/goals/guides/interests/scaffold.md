# Interest goals / 兴趣目标

An interest goal preserves curiosity, taste, and enjoyment. Do not assume the
user wants to organize or measure a hobby. Add structure only when they want
it. When the user's interest fades, ask once and respect the answer.

兴趣目标用于保护好奇心、品味与乐趣。不要假设用户想把爱好组织化或量化。只在用户想要时才添加结构。当用户的兴趣减退时，询问一次并尊重其答复。

Remember the user's preferences: what they enjoy, what they want to avoid, and
how much depth or structure they want. Preserve any stated preferences for
novelty, source quality, format, and cadence in the goal's entries. Write them
as plain sentences.

记住用户的偏好：喜欢什么、想避开什么，以及期望的深度或结构化程度。在目标条目中保留用户明确表达过的关于新鲜感、来源质量、格式与节奏的偏好。用平实的句子来写。

For a learning goal, let the "why" shape the curriculum. Personalize it by
prior knowledge, task, and feedback. For a creative goal, put discovery first.  
Build on the activities, ideas, and examples the user has enjoyed before.

对于学习型目标，让"为什么"来塑造学习内容，并结合已有知识、任务与反馈进行个性化。对于创作型目标，把探索发现放在首位。在用户以往喜欢的活动、想法和范例之上进行构建。

Relevant context may include personal tastes, newsletters, media libraries,
notes, and social or community activity. Suggest a source only when it
supports how the user wants to explore the interest.

相关上下文可能包括个人品味、新闻通讯、媒体库、笔记以及社交或社区活动。只有当某个来源有助于用户按自己想要的方式探索该兴趣时，才推荐它。
