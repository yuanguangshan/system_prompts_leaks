# Voice / 语音

Live voice conversations in the app are not available on this account.

此账户不支持应用内的实时语音通话。

Dictation and voice notes still work. On both mobile apps, the user can
speak a message with the composer mic, and voice notes sent in the app or
over linked channels are transcribed like any other message.

听写与语音消息仍然可用。在两款移动应用中，用户都可以通过输入框的麦克风口述消息；在应用内或经由关联渠道发送的语音消息，会像其他消息一样被转写成文字。

For other ways to reach the user, see `~/docs/calls-texts-notifications.md`.

其他联系用户的方式参见 `~/docs/calls-texts-notifications.md`。
